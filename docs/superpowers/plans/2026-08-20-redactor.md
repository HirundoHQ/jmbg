# Redactor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An `io.WriteCloser` that copies a stream through to a destination, replacing every valid JMBG with 13 asterisks before it lands.

**Architecture:** Same digit-run state machine as `Scanner` (maximal runs of exactly 13 ASCII digits, validated via `Parse`), but the run is *held back* instead of merely observed. Bytes accumulate in an internal output buffer during `Write` and go to `dst` in one `writeAll` at the end, so a per-byte forward never becomes a per-byte syscall. At most 13 bytes are ever held across a `Write` boundary.

**Tech Stack:** Go, standard library only.

**Spec:** `docs/superpowers/specs/2026-08-20-redacting-writer-design.md`

## Global Constraints

- **Zero external dependencies.** Standard library only; lives in the root package next to `scanner.go`.
- **Detection semantics are identical to `Scanner`** — maximal runs of exactly 13 ASCII digits, fully validated via `Parse`. A 14-digit run or a bad checksum passes through untouched.
- **Replacement is exactly 13 asterisks**, length-preserving. Not the `Masked()` partial shape. No configurable replacement.
- **`found` is optional** — `nil` must be accepted.
- **`Write`/`Close` CAN fail**, unlike `Scanner`: `dst.Write` errors are returned as-is. Short writes are looped until complete. After an error the Redactor makes no consistency promises — document "stop using it", write no self-repair logic.
- **`Close` does not close `dst`.**
- Gates: `make all` green, `golangci-lint run` 0 issues, `golangci-lint fmt --diff` empty (note: `run` does **not** check formatting in golangci-lint v2), `go test -cover ./...` at **100.0% of statements**.
- Mutation checks use `Edit` to mutate and `Edit` to revert. **Never `git checkout`.**

### Task 1: The redaction state machine

**Files:**
- Create: `redactor.go`
- Test: `redactor_test.go`

**Interfaces:**
- Consumes: `Parse`, `Match` (`scanner.go`).
- Produces: `func NewRedactor(dst io.Writer, found func(Match)) *Redactor`, with methods `Write([]byte) (int, error)` and `Close() error`.

**The buffering rule** (get this exactly right — it is the whole task):

- **Non-digit byte:** resolve the current run first, then append the byte.
- **Digit byte, `runLen < 13`:** hold it in the run buffer, emit nothing.
- **Digit byte, `runLen == 13`:** this is the 14th digit, so the run can never be a JMBG. Release the 13 held digits, then append this one.
- **Digit byte, `runLen > 13`:** already disqualified — append directly.
- **Run resolved at exactly 13** (non-digit byte or `Close`): `Parse` it. Valid → append the mask and call `found`. Invalid → append the digits unchanged.
- **Run resolved below 13:** append the held digits unchanged.
- **Run resolved above 13:** nothing held, nothing to append.

```go
import (

// redact runs input through a Redactor in chunks of the given size and
// returns everything dst received plus every match reported.
func redact(t *testing.T, input string, chunkSize int) (string, []Match) {
	t.Helper()
	var dst bytes.Buffer
	var got []Match
	r := NewRedactor(&dst, func(m Match) { got = append(got, m) })
	for i := 0; i < len(input); i += chunkSize {
		end := min(i+chunkSize, len(input))
		if _, err := r.Write([]byte(input[i:end])); err != nil {
			t.Fatalf("Write: unexpected error: %v", err)
		}
	}
	if err := r.Close(); err != nil {
		t.Fatalf("Close: unexpected error: %v", err)
	}
	return dst.String(), got
}
```

```go
package jmbg

import "io"

// redactionMask replaces a valid JMBG in a redacted stream. It is 13 bytes
// wide so that redaction preserves the length of the stream.
const redactionMask = "*************"

// Redactor copies a byte stream through to a destination, replacing every
// valid JMBG it finds with 13 asterisks. Detection matches Scanner exactly:
// only maximal runs of exactly 13 ASCII digits are considered, and each is
// validated with Parse, so a 16-digit card number or a bad checksum passes
// through untouched. Everything else is forwarded byte for byte.
//
// Where Scanner reports a leak, Redactor prevents it: wrap a log file, an
// HTTP response, or stdout and the number never reaches the sink.
//
// Redactor implements io.WriteCloser. Writes may be split at any byte
// boundary; a run spanning writes is handled. At most 13 bytes are ever
// held back, so memory and latency are constant, but a run held at a Write
// boundary has not reached dst yet — Close ends the stream, flushes such a
// run, and must be called. Close does not close dst. After Close the
// Redactor may keep being used; offsets continue from where the stream left
// off.
//
// Unlike Scanner, Write and Close can fail: an error from dst is returned
// as is. After an error the Redactor makes no consistency promises — stop
// using it.
//
// The Redactor assumes an ASCII-compatible encoding such as UTF-8, and sees
// only the bytes it is given: decompress (e.g. gzip) and extract text (e.g.
// from PDFs) before redacting.
//
// A Redactor must not be used from multiple goroutines concurrently.
type Redactor struct {
	dst    io.Writer
	found  func(Match)
	run    [13]byte // digits of the current run, while it may still be a JMBG
	runLen int      // true length of the current run, which may exceed len(run)
	pos    int64    // bytes consumed so far
	out    []byte   // output staged for the current Write or Close
}

// NewRedactor returns a Redactor that copies into dst, masking every valid
// JMBG. If found is non-nil it is called for each redacted JMBG, with
// Match.Offset relative to the input stream; because redaction preserves
// length, input and output offsets coincide.
func NewRedactor(dst io.Writer, found func(Match)) *Redactor {
	return &Redactor{dst: dst, found: found}
}

// Write redacts p and forwards it to dst. It returns len(p) and a nil error
// unless dst fails, in which case it returns 0 and that error.
func (r *Redactor) Write(p []byte) (int, error) {
	r.out = r.out[:0]
	for i, c := range p {
		if c >= '0' && c <= '9' {
			r.appendDigit(c)
			continue
		}
		r.endRun(r.pos + int64(i))
		r.out = append(r.out, c)
	}
	r.pos += int64(len(p))
	if err := r.writeAll(r.out); err != nil {
		return 0, err
	}
	return len(p), nil
}

// Close ends the stream, flushing a digit run that touches the final byte.
// It does not close dst.
func (r *Redactor) Close() error {
	r.out = r.out[:0]
	r.endRun(r.pos)
	return r.writeAll(r.out)
}

// appendDigit adds c to the current digit run, releasing the run once it
// grows past 13 digits and can no longer be a JMBG.
func (r *Redactor) appendDigit(c byte) {
	switch {
	case r.runLen < len(r.run):
		r.run[r.runLen] = c
	case r.runLen == len(r.run):
		// The 14th digit disqualifies the whole run: let the held digits go
		// and forward everything after them directly.
		r.out = append(r.out, r.run[:]...)
		r.out = append(r.out, c)
	default:
		r.out = append(r.out, c)
	}
	r.runLen++
}

// endRun terminates the current digit run, which ends just before the given
// stream offset, and stages its replacement.
func (r *Redactor) endRun(end int64) {
	switch {
	case r.runLen == len(r.run):
		if j, err := Parse(string(r.run[:])); err == nil {
			r.out = append(r.out, redactionMask...)
			if r.found != nil {
				r.found(Match{JMBG: j, Offset: end - int64(len(r.run))})
			}
		} else {
			r.out = append(r.out, r.run[:]...)
		}
	case r.runLen < len(r.run):
		r.out = append(r.out, r.run[:r.runLen]...)
	}
	// A run longer than 13 digits was already forwarded by appendDigit.
	r.runLen = 0
}

// writeAll writes b to dst, looping over short writes.
func (r *Redactor) writeAll(b []byte) error {
	for len(b) > 0 {
		n, err := r.dst.Write(b)
		b = b[n:]
		if err != nil {
			return err
		}
		if n == 0 {
			return io.ErrShortWrite
		}
	}
	return nil
}
```

```go
// failWriter fails on the nth Write (1-based); earlier writes succeed.
type failWriter struct {
	n     int
	count int
	err   error
}

func (w *failWriter) Write(p []byte) (int, error) {
	w.count++
	if w.count == w.n {
		return 0, w.err
	}
	return len(p), nil
}

// halfWriter writes at most half of each slice, forcing writeAll to loop.
type halfWriter struct{ buf bytes.Buffer }

func (w *halfWriter) Write(p []byte) (int, error) {
	n := (len(p) + 1) / 2
	return w.buf.Write(p[:n])
}

// stuckWriter accepts nothing but reports no error — writeAll must not spin.
type stuckWriter struct{}

func (stuckWriter) Write([]byte) (int, error) { return 0, nil }

func TestRedactorPropagatesWriteError(t *testing.T) {

	t.Run("from Write", func(t *testing.T) {
		r := NewRedactor(&failWriter{n: 1, err: boom}, nil)
		n, err := r.Write([]byte("JMBG: 0710003730015."))

		}
```

```go
// FuzzRedactor checks two properties: chunking never changes the output,
// and the output is exactly the input with every Scanner-reported match
// replaced by the mask.
func FuzzRedactor(f *testing.F) {
	seeds := []string{
		"JMBG: 0710003730015.",
		"0710003730015 and 0101000710009",
		"00710003730015",
		"4111111111111111",
		`{"jmbg":"0710003730015"}`,
		"0710003730025",
		"Perić: 0710003730015",
		"no digits here",
		"",
	}
	for _, s := range seeds {
		f.Add(s)
	}

	f.Fuzz(func(t *testing.T, input string) {
		var whole bytes.Buffer
		rw := NewRedactor(&whole, nil)
		if _, err := rw.Write([]byte(input)); err != nil {
			t.Fatalf("Write: unexpected error: %v", err)
		}
		if err := rw.Close(); err != nil {
			t.Fatalf("Close: unexpected error: %v", err)
		}

		var split bytes.Buffer
		rs := NewRedactor(&split, nil)
		for i := 0; i < len(input); i++ {
			if _, err := rs.Write([]byte{input[i]}); err != nil {
				t.Fatalf("Write: unexpected error: %v", err)
			}
		}
		if err := rs.Close(); err != nil {
			t.Fatalf("Close: unexpected error: %v", err)
		}

		if whole.String() != split.String() {
			t.Fatalf("chunking changed the output: whole = %q, split = %q",
				whole.String(), split.String())
		}

		// Independent oracle: Scanner says where the JMBGs are.
		want := []byte(input)
		if err := Scan(strings.NewReader(input), func(m Match) {
			copy(want[m.Offset:m.Offset+int64(len(redactionMask))], redactionMask)
		}); err != nil {
			t.Fatalf("Scan: unexpected error: %v", err)
		}
		if whole.String() != string(want) {
			t.Errorf("output = %q, want %q (input with Scanner's matches masked)",
				whole.String(), string(want))
		}
	})
}
```

````markdown
`Scanner` detects a leak; `Redactor` prevents it. It is an `io.WriteCloser`
that forwards a stream byte for byte, replacing each valid JMBG with 13
asterisks before it reaches the destination — same detection rules, so a
````
